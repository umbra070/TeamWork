Teamwork — сервис рекомендаций банковских продуктов

Сервис предназначен для выдачи персонализированных рекомендаций банковских продуктов клиентам банка «Стар». На вход подаётся идентификатор пользователя, на выходе — список продуктов, которые могут быть ему интересны, с названием, ID и текстовым описанием.

MVP реализует три рекомендации: «Invest 500», «Top Saving», «Простой кредит». Каждая рекомендация описана набором правил, которые проверяются по данным о транзакциях пользователя из встроенной H2-базы. Архитектура построена с расчётом на расширение: добавление новой рекомендации сводится к созданию нового класса-правила.

Стек технологий: Java 17, Spring Boot 4.1.0 (Spring Web, Spring JDBC), H2 2.4.240, springdoc-openapi 3.1.1, Maven, JUnit 5 + Mockito. Доступ к БД — через JdbcTemplate в режиме read-only. Архитектура слоистая с паттерном «Стратегия» для правил рекомендаций.
